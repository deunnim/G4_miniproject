# Group Vocabulary App — Streamlit Version

## 1. Group Information
- Group: 4
- Members (역할): 정든님 (app-building), 김수현 (app-building), 정해윤 (readme2.md), 박정휴 (readme2.md)
- Project link: [Our project link](https://github.com/deunnim/G4_miniproject)

## 2. Target Learners
중학교 2학년을 대상으로 앱을 설계함.

## 3. Learning Goal
3000개의 단어를 파악하고 그것의 variation, word-family 등을 학습할 수 있게 함.

## 4. What We Updated
Write what you changed from the first version. Use lists.
+ 10개의 단어만 골랐던 반면에 3000개의 단어를 전부 학습할 수 있도록 단어의 폭을 넓힘.
+ 객관식과 fill in the blanks 문제에서 제시한 예문이 단어를 맞추기에 충분한 clue를 제공하지 못해 수정함.

## 5. Main Features
- Read the passage and fill in the blanks
- Example sentences를 통한 단어 guessing quiz
- level별, day별 학습

## 6. Vocabulary Data
기존에 만들어둔 앱에 3000개의 단어 파일을 합쳐서 앱을 강화하고 그것을 streamlit에 맞도록 변환하여 링크만 있다면 할 수 있게끔 설계함.
[Our 3000 vocabulary list](https://github.com/deunnim/G4_miniproject/blob/main/Voca_3000.xlsx%20-%20Vocabulary.csv)

## 7. What We Learned Through This Group Activity
다수의 학생이 학습함과 동시에 결과를 집계해서 볼 수 있는 앱을 만드는 것이 상당히 어렵다는 것을 알게 되었다. 그렇기에 향후 교사로서 학습용 앱을 조직하고, 설계하고, 운용해 보는 경험을 갖게 되어 좋았다.
